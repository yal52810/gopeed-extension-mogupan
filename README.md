# 极速盘下载插件 (GoPeed 扩展)

配合解析页使用的 GoPeed 下载扩展：直链自动附加防盗链请求头，中转链接透传下载，分享链接引导到解析页一键推送。**无需填写卡号，无任何凭证设置。**

## 功能

- **直链下载**：识别 CDN 直链（`*.cainiu.xyz`），自动附加 Referer / User-Agent 防盗链头，并预取真实文件名、大小
- **中转链接**：识别自有服务器的中转下载链接（`/api/download/`、`/dl/` 等），直接透传（服务端已注入防盗链头）
- **分享链接**：粘贴分享链接（`moguwp.com` / `mogupan.net`）时提示到解析页解析后一键推送
- 其他链接一律不干预，交给 GoPeed 内置解析

## 安装

方式一（推荐，国内可用）：GoPeed → 扩展 → ➕ → 安装 → 输入 Gitee 仓库地址：

```
https://gitee.com/<你的用户名>/gopeed-extension-jisupan
```

方式二（开发者）：GoPeed → 扩展 → ➕ → 安装 → 选择本地目录，选中本项目文件夹。

方式三（手动包）：Gitee 不可用时下载 zip 解压后按方式二选择解压目录：

```
https://pan.f11.yoga/dist/jisupan-extension-v2.0.0.zip
```

> 本扩展 name 为 `jisupan-downloader`，与旧版扩展不是同一个扩展 ID，**旧扩展需手动卸载**。

## 使用流程

1. GoPeed 桌面端：设置 → 高级 → 通讯协议 TCP `127.0.0.1:9999`，重启。
2. 浏览器打开解析页：`https://pan.f11.yoga/jisupan.html`（电脑建议用 `http://localhost:3000/jisupan.html`，可直连本机 GoPeed）。
3. 输入卡号（自动验证）和分享链接 → 解析。
4. 选择下载方式：
   - **GoPeed 高速下载**：一键推送任务到本机 GoPeed
   - **浏览器下载**：中转地址，免装软件
   - **复制**：手机或推不动 GoPeed 时，到 GoPeed 新建任务粘贴链接，本扩展自动附加请求头

## 设置

| 设置项 | 默认值 | 说明 |
|---|---|---|
| 服务器地址 | `https://pan.f11.yoga` | 解析页所在服务器，仅用于拼接解析页地址提示 |

## 常见问题

- **直链下载失败 / 下载下来是网页？** 直链有时效，过期后请回解析页重新解析。
- **手动粘贴的直链偶尔失败？** 手动粘贴时扩展使用通用防盗链 Referer；建议用解析页的「GoPeed 高速下载」按钮推送，会使用精确的 Referer。
- **手机怎么用？** 手机浏览器打开解析页 → 复制链接 → 手机 GoPeed 新建任务粘贴（扩展自动接管）；或直接「浏览器下载」。
- **浏览器下载为什么也能下？** 中转地址由服务器代发请求并注入防盗链头，所以浏览器也能直接下，无需扩展。
